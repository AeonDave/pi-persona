# Banner concepts

Three banner concepts. **A — Prism** was selected and copied unchanged to [`../banner.png`](../banner.png).
The alternatives are retained for reference. B also supplied the visual style for the explanatory
[workflow illustration](../workflow.png); its [edit prompt](../workflow.prompt.md) records that adaptation.

Generated with the built-in image generation tool. These are branding illustrations, not product screenshots.

## Generation prompts

### a-prism

```text
Use case: ads-marketing.
Asset type: polished GitHub README hero banner for the existing open-source developer tool pi-persona. Generate a NEW original wide raster banner, approximately 1536x640, 2.4:1 landscape.
Project meaning: switchable AI supervisor personas, specialist subagents, live supervision. This is visual branding, NOT a screenshot or a detailed diagram.
Creative direction: PRISM. Restrained high-end dark editorial design. Deep midnight charcoal background with subtle texture; a beautifully sculpted cluster of three abstract geometric persona masks, translucent smoked glass with fine cyan, teal and violet rim refractions. Distinct overlapping face profiles imply one supervisor with multiple perspectives; abstract, no eyes staring, no realistic human portraits. Tiny carefully placed connection lines can suggest collaboration, very sparse.
Layout: large immaculate lowercase wordmark "pi-persona" with strong, clean modern sans-serif typography and generous spacing; an independent visual cluster balances the type in a spacious asymmetrical composition. Title must be the clear first read at thumbnail size. Subtitle below, restrained and readable: "Personas and multi-agent collaboration for Pi". Render these exact two text strings only. No additional slogan or labels. Safe margins about 7 percent all around.
Style: premium creative developer-tool identity, refined optical glass and matte surfaces, controlled cinematic lighting, calm negative space, crisp typography. No stock robot clipart, no brain icon, no cyberpunk city, no fake code, no crowded schematic, no watermark, no framing browser mockup. Full-bleed opaque background.
```

### b-mission-control

```text
Use case: ads-marketing.
Asset type: original GitHub README hero banner for the open-source tool pi-persona. NEW wide raster image approximately 1536x640, 2.4:1 landscape. Branding illustration, NOT a screenshot of the product.
Project meaning: one AI supervisor coordinates a team of specialists; user sees progress and can guide workers.
Creative direction: MISSION CONTROL. Beautiful restrained terminal-inspired technical poster, near-black ink background, precise phosphor mint/cyan linework, warm off-white type. A single prominent hub with a simple abstract pi glyph connects through beautifully routed thin parallel traces to four smaller geometric specialist modules. Minimal schematic-inspired composition, a few tiny status dots, meticulous spacing; no dense circuitboard texture. The cluster conveys organized independent work converging to one outcome.
Typography: huge lowercase text "pi-persona" in an elegant monospaced-inspired technical typeface. Secondary exact text "Personas and multi-agent collaboration for Pi". Only these two strings; do not add tool names, terminal commands, version numbers or labels. Compose with abundant negative space, balance large title and graphic, keep all content at least 7 percent from edges. Strong readability at 900px wide on GitHub.
Finish: crisp thin lines with tiny controlled phosphor glow, editorial grid, subtle paper/CRT grain but no scanline distortion. Serious precise understated developer aesthetic. No masks, no photoreal faces, no robots, no purple gradient blobs, no busy HUD, no fake screenshot, no watermark. Full-bleed opaque background.
```

### c-ensemble

```text
Use case: ads-marketing.
Asset type: new original GitHub README hero banner for pi-persona, an open-source AI multi-agent orchestration extension. Wide raster approximately 1536x640, 2.4:1 landscape.
Creative direction: ENSEMBLE. Sophisticated light editorial identity, warm ivory matte paper background, deep ink/navy typography, a bold abstract composition of three interlocking persona profile silhouettes in rich cobalt, muted teal and a small warm coral accent. The profiles should feel like clever cut-paper geometric masks forming one coordinated ensemble, not portraits or cartoon characters. Subtle embossed depth and soft paper shadows, mostly graphic shapes with clear silhouettes. One small connecting line motif suggests collaboration.
Typography: beautifully typeset extra-large lowercase title "pi-persona", strong modern grotesk, immaculate kerning, not decorative. Subtitle exact text "Personas and multi-agent collaboration for Pi". Only these two text strings, no slogan or labels. Art and type share a balanced asymmetrical grid with generous whitespace, 7 percent safe margins, readable when displayed 900px wide.
Mood: confident, intelligent, approachable, visually distinctive open-source developer project, clean Swiss-editorial-inspired composition. No robots, no brain icons, no fake code, no tiny diagram labels, no gradients washing out the typography, no watermarks. Full-bleed opaque background.
```
